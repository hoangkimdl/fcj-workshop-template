  • Thực hành triển khai các ứng dụng mã nguồn mở trên Amazon Lightsail, bao gồm WordPress phục vụ xây dựng Blog/Website, PrestaShop phục vụ xây dựng Website thương mại điện tử và Akaunting phục vụ quản lý tài chính.
  • Tìm hiểu sự khác nhau giữa OS Blueprint và Application Blueprint trong Amazon Lightsail, hiểu được cách lựa chọn Blueprint phù hợp với từng ứng dụng cần triển khai.
  • Thực hành cấu hình Ubuntu, thiết lập Networking và hoàn thiện quá trình triển khai, kiểm tra hoạt động của các ứng dụng WordPress, PrestaShop và Akaunting.
  • Tìm hiểu các phương pháp tăng cường bảo mật cho ứng dụng được triển khai trên Amazon Lightsail, bảo vệ hệ thống khỏi những rủi ro phát sinh từ cấu hình mặc định.
  • Tìm hiểu và thực hành tạo Snapshot để sao lưu trạng thái Instance, hỗ trợ khôi phục ứng dụng và bảo vệ dữ liệu khi xảy ra sự cố.
  • Tìm hiểu cách nâng cấp Lightsail Instance lên cấu hình lớn hơn nhằm đáp ứng nhu cầu sử dụng tài nguyên khi ứng dụng phát triển.
  • Thực hành tạo và cấu hình Alarm để giám sát tài nguyên, theo dõi tình trạng hoạt động của hệ thống và thiết lập cảnh báo khi phát sinh các vấn đề cần xử lý.
  • Tìm hiểu tổng quan về Amazon Lightsail Container, vai trò của Container Service trong việc triển khai các ứng dụng được đóng gói bằng Docker Image mà không cần tự quản lý toàn bộ hạ tầng container.

  • Tìm hiểu Docker, AWS CLI và IAM trong quy trình xây dựng, quản lý và triển khai Container Image lên Amazon Lightsail.
  • Thực hành tạo Lightsail Instance sử dụng Ubuntu 20.04 LTS làm môi trường xây dựng Docker Image, cài đặt AWS CLI, Lightsail Control Plugin và Docker.
  • Thực hành xây dựng Docker Image của ứng dụng, đẩy Image lên Docker Hub hoặc Amazon Lightsail Container Service và triển khai phiên bản mới trên môi trường Container.
  • Nắm được quy trình quản lý Deployment, kiểm tra trạng thái hoạt động của Container và truy cập ứng dụng thông qua Public Domain được Amazon Lightsail cung cấp.

- Truy cập AWS Management Console và mở Amazon Lightsail để bắt đầu quá trình triển khai ứng dụng.
- Thực hành truy cập phần Instances và lựa chọn Create Instance để khởi tạo máy chủ phục vụ triển khai WordPress.
- Tìm hiểu các tùy chọn nền tảng Linux/Unix, hệ điều hành và Blueprint được sử dụng trong quá trình khởi tạo Instance.
- Thực hành triển khai WordPress trên Amazon Lightsail bằng OS Blueprint theo hướng dẫn Workshop.
- Tìm hiểu và thực hành các bước cấu hình Ubuntu phục vụ quá trình triển khai WordPress, bao gồm chuẩn bị môi trường hệ điều hành và các thành phần cần thiết cho ứng dụng.

5Tìm hiểu Amazon Lightsail Container và thực hành tạo Container Service, triển khai Public Container Image

- Tìm hiểu tổng quan về Amazon Lightsail Container, dịch vụ cho phép triển khai các ứng dụng được đóng gói bằng Docker Images lên môi trường Cloud thông qua giao diện quản lý đơn giản.
- Tìm hiểu vai trò của Container trong việc đóng gói ứng dụng cùng các thư viện, dependencies và môi trường thực thi cần thiết, giúp đảm bảo tính nhất quán khi triển khai trên các hệ thống khác nhau.
- Tìm hiểu Docker và vai trò của Docker Image trong việc xây dựng, đóng gói và triển khai ứng dụng dưới dạng Container.
- Tìm hiểu lợi ích của Amazon Lightsail Container Service trong việc đơn giản hóa quá trình triển khai ứng dụng, giảm yêu cầu quản lý cơ sở hạ tầng và hỗ trợ phát hành các phiên bản ứng dụng mới.
- Tìm hiểu các thành phần cơ bản của Lightsail Container Service, bao gồm Container Service, Container Images, Deployments, Public Endpoint và Container Scaling.
- Tìm hiểu AWS Command Line Interface (AWS CLI), công cụ hỗ trợ quản lý các dịch vụ AWS thông qua dòng lệnh và thực hiện các thao tác tự động hóa.
- Tìm hiểu AWS Identity and Access Management (IAM), vai trò của IAM User, Access Key và Secret Access Key trong việc xác thực và quản lý quyền truy cập các tài nguyên AWS.
- Tìm hiểu Docker và các thao tác cơ bản trong việc xây dựng, quản lý và triển khai Docker Images trên Amazon Lightsail.
- Truy cập AWS Management Console và mở Amazon Lightsail, lựa chọn mục Containers để bắt đầu tạo Container Service.
- Thực hành lựa chọn Create container service, chọn AWS Region Singapore (ap-southeast-1) theo hướng dẫn Workshop.
- Lựa chọn cấu hình Container Service phù hợp dựa trên tài nguyên CPU, Memory và chi phí sử dụng.
- Đặt tên Container Service là lightsail-container theo hướng dẫn trong phần tạo Container Service và lựa chọn Create container service.
- Theo dõi quá trình khởi tạo Container Service cho đến khi trạng thái chuyển sang Ready.
- Truy cập tab Deployments và lựa chọn Create your first deployment để tạo Deployment đầu tiên.
- Thực hành cấu hình Container Name và Image Name, sử dụng Public Container Image chính thức nginx từ Docker Hub.
- Tìm hiểu cách cấu hình các thông số tùy chọn cho Container, bao gồm Initial run commands, Environment variables và Network ports.
- Cấu hình Port 80 và lựa chọn Protocol HTTP để cho phép người dùng truy cập Nginx Container thông qua giao thức HTTP.
- Thiết lập Public Endpoint để phân phối lưu lượng truy cập đến Nginx Container thông qua Port 80 và giữ nguyên Health Check Path mặc định là /.
- Lựa chọn Save and deploy để bắt đầu triển khai Container Image lên Container Service.
- Theo dõi trạng thái triển khai từ Deploying đến Active và kiểm tra thông tin Public Domain được Amazon Lightsail cung cấp.
- Truy cập Public Domain trên trình duyệt để xác nhận Nginx Container đã được triển khai thành công và có thể phục vụ nội dung qua HTTP.
- Tìm hiểu quy trình triển khai Public Container Image từ Docker Hub, hiểu được cách sử dụng một Image có sẵn mà không cần tự xây dựng Docker Image.
- Tổng hợp các bước tạo Container Service và triển khai ứng dụng Nginx nhằm chuẩn bị cho phần xây dựng và triển khai Container Image riêng.		19/11/202619/11/2026Amazon Lightsail Container - Run Apps on Lightsail Container

6Thực hành xây dựng Docker Image, đẩy Image lên Registry, triển khai phiên bản mới và dọn dẹp tài nguyên

- Tìm hiểu quy trình xây dựng và triển khai Container Image riêng trên Amazon Lightsail, bao gồm chuẩn bị môi trường, cài đặt Docker, xây dựng Image, đẩy Image lên Registry và tạo Deployment mới.
- Tìm hiểu cách sử dụng Amazon Lightsail Instance làm môi trường xây dựng Docker Image và thực hiện các thao tác quản lý Container thông qua AWS CLI.
- Truy cập Lightsail Console và thực hành tạo Lightsail Instance mới để làm môi trường Build.
