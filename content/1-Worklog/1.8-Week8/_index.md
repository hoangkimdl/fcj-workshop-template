### Week 8 Objectives:

- Understand the fundamentals of Amazon Lightsail, its role in providing virtual servers, storage, and networking resources, and its simplified pricing model for deploying applications on AWS Cloud.
- Practice deploying open-source applications on Amazon Lightsail, including WordPress for building blogs and websites, PrestaShop for developing e-commerce websites, and Akaunting for financial management.
- Understand the differences between OS Blueprints and Application Blueprints in Amazon Lightsail and learn how to select appropriate Blueprints for different application deployment requirements.
- Practice configuring Ubuntu, setting up Networking, and completing the deployment of WordPress, PrestaShop, and Akaunting applications.
- Learn application security practices for protecting applications deployed on Amazon Lightsail and reducing risks associated with default configurations.
- Understand and practice creating Snapshots to back up Instance configurations, restore applications, and protect data in case of unexpected failures.
- Learn how to upgrade Lightsail Instances to larger configurations to accommodate increasing application resource requirements.
- Practice creating and configuring Alarms to monitor system resources, track system performance, and receive notifications when predefined thresholds are reached.
- Understand Amazon Lightsail Container and its role in deploying Docker-based applications without having to manage the entire container infrastructure.
- Practice creating an Amazon Lightsail Container Service, selecting an AWS Region, configuring resources, and deploying Nginx from a Public Container Image.
- Learn about Docker, AWS CLI, and IAM in the process of building, managing, and deploying Container Images to Amazon Lightsail.
- Practice creating a Lightsail Instance running Ubuntu 20.04 LTS as a Docker Image build environment, installing AWS CLI, Lightsail Control Plugin, and Docker.
- Practice building application Docker Images, pushing Images to Docker Hub or Amazon Lightsail Container Service, and deploying new application versions.
- Understand how to manage Deployments, monitor Container status, and access applications through the Public Domain provided by Amazon Lightsail.
- Understand the resource cleanup process, including Lightsail Instances, Container Services, Docker Images, and related tools, to minimize unnecessary AWS charges after completing the workshops.
