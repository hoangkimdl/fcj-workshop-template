Week 8 Worklog

Week 8 Objectives:

  • Understand the fundamentals of Amazon Lightsail, its role in providing virtual servers, storage, and networking resources, and its simplified pricing model for deploying applications on AWS Cloud.
  • Practice deploying open-source applications on Amazon Lightsail, including WordPress for building blogs and websites, PrestaShop for developing e-commerce websites, and Akaunting for financial management.
  • Understand the differences between OS Blueprints and Application Blueprints in Amazon Lightsail and learn how to select appropriate Blueprints for different application deployment requirements.
  • Practice configuring Ubuntu, setting up Networking, and completing the deployment of WordPress, PrestaShop, and Akaunting applications.
  • Learn application security practices for protecting applications deployed on Amazon Lightsail and reducing risks associated with default configurations.
  • Understand and practice creating Snapshots to back up Instance configurations, restore applications, and protect data in case of unexpected failures.
  • Learn how to upgrade Lightsail Instances to larger configurations to accommodate increasing application resource requirements.
  • Practice creating and configuring Alarms to monitor system resources, track system performance, and receive notifications when predefined thresholds are reached.
  • Understand Amazon Lightsail Container and its role in deploying Docker-based applications without having to manage the entire container infrastructure.
  • Practice creating an Amazon Lightsail Container Service, selecting an AWS Region, configuring resources, and deploying Nginx from a Public Container Image.
  • Learn about Docker, AWS CLI, and IAM in the process of building, managing, and deploying Container Images to Amazon Lightsail.
  • Practice creating a Lightsail Instance running Ubuntu 20.04 LTS as a Docker Image build environment, installing AWS CLI, Lightsail Control Plugin, and Docker.
  • Practice building application Docker Images, pushing Images to Docker Hub or Amazon Lightsail Container Service, and deploying new application versions.
  • Understand how to manage Deployments, monitor Container status, and access applications through the Public Domain provided by Amazon Lightsail.
  • Understand the resource cleanup process, including Lightsail Instances, Container Services, Docker Images, and related tools, to minimize unnecessary AWS charges after completing the workshops.

FridayBuilding Docker Images, Pushing Images to a Registry, Deploying New Versions, and Cleaning Up Resources

- Learn the process of building and deploying custom Container Images on Amazon Lightsail, including environment preparation, Docker installation, Image building, pushing Images to a Registry, and creating new Deployments.
- Understand how to use an Amazon Lightsail Instance as a Docker Image build environment and perform Container management operations through AWS CLI.
- Access Lightsail Console and practice creating a new Lightsail Instance for the build environment.
- Select the Linux/Unix platform, navigate to Blueprint → OS Only, and choose Ubuntu Linux 20.04 LTS according to the Workshop instructions.
- Name the Lightsail Instance Build-Instance and select Create Instance to provision the server.
- Wait until the Instance status changes to Running, then use the Command Line option to connect to Build-Instance through the browser-based Terminal.
- Practice installing the unzip utility on Ubuntu using sudo apt-get install -y unzip to prepare the environment for AWS CLI installation.
- Install AWS CLI v2 by downloading the installation package from AWS, extracting it, and running the installation commands:
  + sudo curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip".
  + sudo unzip awscliv2.zip.
  + sudo ./aws/install.
- Practice installing the Lightsail Control Plugin (lightsailctl) to interact with Amazon Lightsail Container Service through AWS CLI.
- Download the lightsailctl utility from AWS and grant execution permissions using sudo chmod +x /usr/local/bin/lightsailctl according to the Workshop instructions.
- Learn how to create an IAM User named awsstudent, select Administrator Access permissions according to the Workshop configuration, and generate an Access Key and Secret Access Key for AWS CLI configuration.
- Understand how to configure AWS CLI using Access Key ID, Secret Access Key, Default Region, and Output Format to allow the build server to interact with AWS services.
- Learn IAM credential protection practices and avoid storing or sharing Access Keys and Secret Access Keys in source code or public locations.
- Practice installing Docker on Ubuntu according to the Installing Docker on Ubuntu for AWS Lightsail instructions.
- Verify the Docker installation and become familiar with basic commands for managing Docker Images and Containers.
- Learn about Dockerfile structure and the role of its instructions in defining the build environment, application components, and Container runtime configuration.
- Practice preparing the fcj-nginx application source directory and necessary files to build a custom Docker Image according to the Workshop instructions.
- Use Docker to build a Container Image from the Dockerfile, creating an Image named fcj-nginx with the version Tag v1 according to the deployment procedure.
- Check the list of Docker Images after building to verify that fcj-nginx:v1 has been created successfully.
- Learn how to push Docker Images to Docker Hub or Amazon Lightsail Container Service for storage and deployment.
- Practice authenticating and using AWS CLI together with Lightsail Control Plugin to push the Container Image to Amazon Lightsail Container Service according to the Workshop instructions.
- Access the previously created Container Service, open the Deployments tab, and create a new Deployment using the custom Container Image that was built and uploaded.
- Configure the necessary Container settings, including Container Name, Image, and appropriate Port; verify the configuration before deployment.
- Select Save and deploy to deploy the new Container Image version to Lightsail Container Service.
- Monitor the Deployment status, verify that it reaches Active, and access the Public Domain to confirm that the application is running successfully.
- Learn the application update process by building a new Docker Image, pushing it to a Registry, and deploying a new Deployment on Lightsail.
- Practice deleting the Container Service after completing the Workshop by opening the menu beside the Container Service tabs, selecting Delete → Delete container service, and confirming Yes, delete.
- Understand that deleting a Container Service also removes its associated Deployments and Container Images stored within that Service.
- Access AWS CloudShell and practice cleaning up Docker Images, working directories, and the local Lightsail Control Plugin using the commands provided in the Workshop:

  + docker rmi -f fcj-nginx:v1.
  + rm -rf ~/fcj-nginx ~/.local/bin/lightsailctl.

- Verify that the returned result is [], indicating that no Container Service matching the query remains.
